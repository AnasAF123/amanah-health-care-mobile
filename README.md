# Amanah Healthcare Mobile App

Official mobile application for Amanah Healthcare.

## Overview

Amanah Healthcare is designed to empower users with transparent and reliable healthcare, nutrition, and product information.

## Getting Started

### Prerequisites

- Flutter SDK (version 3.38 or later)
- Android Studio / VS Code with Flutter extension
- Xcode (for iOS/macOS development)

### Running the Application

Navigate to `packages/amanah_healthcare` directory:

```bash
cd packages/amanah_healthcare
flutter pub get
```

Run target per platform:
- **Android**: `flutter run -t lib/entrypoints/android/main_google_play.dart`
- **iOS / macOS**: `flutter run -t lib/entrypoints/ios/main_ios.dart`
